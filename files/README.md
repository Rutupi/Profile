# Rutuparn Ranade — Portfolio

Personal portfolio website built with HTML, CSS, and vanilla JS. Served via Node.js + Express.

## Quick Start

```bash
npm install
npm start
```

Visit http://localhost:3000

## Dev Mode (auto-reload)

```bash
npm run dev
```

## Deploy to Vercel

```bash
npm i -g vercel
vercel
```

## Deploy to Railway / Render

Set environment variable:
- `PORT` — defaults to 3000 if not set
